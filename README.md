# PillVision

PillVision выделяет объекты на изображении, разделяет слипшиеся объекты, считает их и отмечает касания. Источником может быть веб-камера, видеофайл, снимок или область экрана. В потоковых режимах программа отслеживает объекты между кадрами.

## Установка на Windows

Понадобится Python 3.10 или новее. В PowerShell выполните команды из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Быстрый запуск

По умолчанию программа открывает веб-камеру с индексом `0` и показывает результат в окне OpenCV.

```powershell
.\.venv\Scripts\python.exe -B main.py
```

Для первой проверки без камеры обработайте контрольное изображение. Ожидаемый результат — один объект.

```powershell
.\.venv\Scripts\python.exe -B main.py --source image --input test_images/09_single.png --no-gui
```

## Источники и параметры

Команды ниже предполагают, что окружение активировано командой `.\.venv\Scripts\Activate.ps1`. Также можно запускать `.\.venv\Scripts\python.exe` напрямую.

| Задача | Команда |
| --- | --- |
| Выбрать камеру с индексом 1 | `python -B main.py --camera 1` |
| Обработать видеофайл | `python -B main.py --source video --input "C:/Videos/sample.mp4"` |
| Захватить область экрана | `python -B main.py --source screen --region 100,100,800,600` |
| Сохранить размеченное изображение | `python -B main.py --source image --input test_images/09_single.png --no-gui --save-result result.png` |
| Посмотреть все параметры | `python -B main.py --help` |

`--region` задаёт левую и верхнюю координаты, ширину и высоту в пикселях. Без региона захватывается весь экран. `--background PATH` загружает снимок фона, а `--debug` показывает промежуточные изображения в дополнительных окнах. `--min-area` задаёт минимальную площадь объекта, а `--contact-gap` позволяет настроить порог расстояния между контурами для касания.

В окне потокового источника доступны клавиши:

- `q` — выйти.
- `b` — запомнить текущий кадр как фон. Для калибровки уберите объекты из кадра перед нажатием.
- `c` — сбросить фон.
- `s` — сохранить размеченный кадр, если задан `--save-result`.

## Автоподбор для веб-камеры

Перед открытием окна программа проверяет, какие режимы дают кадры. В Windows она пробует DirectShow и Media Foundation с параметрами камеры по умолчанию и с запросом MJPEG 640×480 при 30 кадр/с. Программа замеряет захват и обработку, подбирает число потоков OpenCV и при близкой скорости отдаёт предпочтение большему разрешению. Выбранный режим отображается в консоли.

Чтобы замерить скорость обработки на своей сцене, выполните ограниченный прогон без окна. В конце программа выведет число обработанных кадров и среднюю скорость. Для сравнения с настройками OpenCV по умолчанию повторите команду с `--no-camera-tune`.

```powershell
python -B main.py --no-gui --max-frames 60 --quiet
```

Если программа сообщает «Не удалось получить кадр», проверьте изображение в приложении Windows «Камера», затем закройте его и повторите запуск. При нескольких видеоустройствах проверьте другой индекс через `--camera`.

## Тесты

Синтетические тесты проверяют одиночные объекты, группы с касаниями, подавление теней и фильтрацию мелкого шума.

```powershell
python -B tests/test_synthetic.py
```

Контрольные изображения лежат в [`test_images/`](test_images/), снимки тестовой сцены — в [`test_images/images/`](test_images/images/). Чтобы сгенерировать воспроизводимую сцену и сравнить число нарисованных и найденных объектов, выполните:

```powershell
python -B main.py --generate-test --generate-count 8 --generate-seed 42 --generate-out scene.png --auto-check
```
